# Personal Portfolio — Kyaw Zin Soe

Portfolio website for a Laravel Full-Stack Developer. Built with React, TypeScript, Tailwind CSS and Vite.

## Tech Stack

- React + TypeScript
- Tailwind CSS v4
- Vite
- lucide-react

## Features

- Dark / light theme toggle
- Fully responsive layout with mobile menu
- Scroll-reveal animations
- Skills, featured projects and contact sections

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Customization

All personal content lives in `src/data/portfolio.ts` — name, email, social links, skills and projects. Profile photo goes in `public/profile.jpg`.
